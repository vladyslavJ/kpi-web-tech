# MCP-сервер для LM Studio

## Що це

MCP-сервер, через який локальна мовна модель у LM Studio працює з базою технологічних карт з лабораторних 4–5 (MongoDB, база `lab05`): отримує дані з таблиць, сортує їх і шукає потрібне. Сервер надає шість інструментів лише для читання: зведення по базі, список деталей, список видів обробки, технологічні карти з сортуванням і фільтрами, повну карту деталі за позначенням і пошук за словом.

## Технології та як це працює

- `server/`: Python 3.12, офіційний MCP SDK (`MCPServer`), асинхронний PyMongo, Uvicorn.
- `lmstudio/mcp.json`: готовий запис для підключення сервера в LM Studio.
- `compose.yaml`: MongoDB 8 у Docker-контейнері `kpi-labs-mongo` (спільний з лабами 4–5) на порту 27018.

LM Studio отримує від сервера описи інструментів зі схемами параметрів, і модель сама вирішує, який інструмент викликати й з якими аргументами. Сортування, фільтри й пошук виконує MongoDB конвеєрами агрегації (`$lookup`, `$sort`, `$match`, `$facet`) з українською колацією. Пошук не враховує регістр, а текст запиту екранується. Інструменти позначені як «лише читання», а помилки (база недоступна, карти не знайдено) повертаються моделі зрозумілим текстом із підказкою. Сервер працює через Streamable HTTP на `http://localhost:8765/mcp` або через stdio, коли LM Studio запускає його сам.

## Запуск

Потрібні Python 3.12+, Docker із Compose, bash і `setsid`, а також LM Studio 0.3.17+ з моделлю, яка вміє викликати інструменти. Скрипт сам створить віртуальне середовище й запустить контейнер MongoDB, якщо той ще не працює. Ctrl+C зупиняє все, а також контейнер, якщо його запустив скрипт.

- `./run.sh dev` запускає сервер на http://localhost:8765/mcp у режимі розробки: він перезапускається при змінах коду, а логи читабельні.
- `./run.sh prod` спершу перевіряє код лінтером ruff і типи за допомогою mypy, потім запускає сервер на тій самій адресі з логами в JSON.

Щоб підключити сервер, у LM Studio відкрийте вкладку Program, натисніть Install → Edit mcp.json і додайте запис із `lmstudio/mcp.json`. Якщо LM Studio працює на іншому комп’ютері, прокиньте порт 8765 через вкладку PORTS у VS Code або командою `ssh -L 8765:localhost:8765`.
