# Telegram-бот з AI

## Що це

Telegram-бот із меню з методички: «Студент» (ПІБ, група, варіант), «IT-технології» (список технологій з описами на inline-кнопках), «Контакти» та «Prompt AI». Будь-яке повідомлення, яке не є пунктом меню, бот передає мовній моделі через Groq і пам'ятає контекст розмови, а `/new` починає розмову спочатку. Бот розгортається на PythonAnywhere.

## Технології та як це працює

- `bot/`: Python 3.12, pyTelegramBotAPI, Groq SDK (модель `openai/gpt-oss-120b`), Flask, Pydantic Settings і SQLite.
- Логіка меню та запитів до AI працює через інтерфейси й не залежить від Telegram, Groq чи сховища. Адаптери до них підключаються в одному місці (`bot/src/bot/app.py`).

Локально бот забирає оновлення через long polling і показує сторінку статусу. На PythonAnywhere Telegram надсилає оновлення на вебхук `/telegram/webhook`, який перевіряє секретний заголовок і відкидає повторні оновлення. Відповіді AI перетворюються з Markdown у HTML для Telegram і діляться на частини до 4096 символів. Історія розмов зберігається в `bot/data/bot.sqlite3`.

## Запуск

Потрібні Python 3.12+, bash і `setsid`. Скопіюйте `bot/.env.example` у `bot/.env` і вкажіть `TELEGRAM_BOT_TOKEN` (від @BotFather), `GROQ_API_KEY` (з console.groq.com) і контакти. Залежності скрипт встановить сам, Ctrl+C зупиняє все.

- `./run.sh dev` відкривається на http://localhost:8000. Це режим розробки: бот перезапускається при змінах коду, а логи читабельні.
- `./run.sh prod` відкривається на http://localhost:8000. Спершу скрипт перевіряє код лінтером і типи, потім запускає бота з JSON-логами.

Локальний запуск вимикає вебхук. Після нього перезавантажте вебзастосунок на PythonAnywhere, і бот знову зареєструє вебхук.

На PythonAnywhere:

1. У Bash-консолі клонуйте репозиторій, створіть віртуальне середовище Python 3.12 і встановіть `bot/requirements.txt`.
2. Створіть `bot/.env` з токенами, `WEBHOOK_BASE_URL=https://<логін>.pythonanywhere.com` і випадковим `WEBHOOK_SECRET`.
3. На вкладці Web створіть застосунок (Manual configuration, Python 3.12) і вкажіть шлях до віртуального середовища. У WSGI-файлі додайте теку `bot/src` до `sys.path` та імпортуйте `application` з `bot.wsgi`.
4. Натисніть Reload. Застосунок сам зареєструє вебхук. Стан видно на `https://<логін>.pythonanywhere.com`, а перевірити все можна командою `python -m bot check`.
