# Технологічні карти на FastAPI

## Що це

Вебзастосунок на FastAPI для бази даних технологічних карт деталей (варіант 11: деталь, вид обробки, тривалість обробки). Для деталей, видів обробки й технологічних карт реалізовано повний CRUD: додавання, перегляд усіх записів і одного запису, редагування та видалення. Клієнт той самий, що в лабі 4, а нова сторінка «API» показує інтерактивну документацію Swagger UI. На ній можна надіслати будь-який запит до сервера й побачити відповідь.

## Технології та як це працює

- `api/`: сервер на Python 3.12, FastAPI, Pydantic і асинхронному PyMongo, запускається через Uvicorn.
- `web/`: клієнт на Angular 22 з лаби 4 і Swagger UI.
- `contracts/`: типи запитів і відповідей для клієнта, сервер описує ті самі структури моделями Pydantic.
- `compose.yaml`: MongoDB 8 у Docker-контейнері `kpi-labs-mongo` (спільний з лабою 4) на порту 27018, база `lab05`.

FastAPI будує схему OpenAPI 3.1 з моделей Pydantic і віддає її за адресою `/api/openapi.json`, а сторінка «API» відображає її через Swagger UI. Запити перевіряються моделями Pydantic і правилами домену, а сама MongoDB додатково захищена валідаторами `$jsonSchema` і унікальними індексами. Помилки мають той самий формат і ті самі коди, що й у лабі 4: 400, 404, 409, 413, 422 і 503, а для непідтримуваного методу 405.

## Запуск

Потрібні Python 3.12+, Node.js 24+, Docker із Compose, bash і `setsid`. Скрипт сам створить віртуальне середовище, встановить залежності й запустить контейнер MongoDB, якщо той ще не працює. Ctrl+C зупиняє все, а також контейнер, якщо його запустив скрипт.

- `./run.sh dev` відкривається на http://localhost:4200. Це режим розробки: сервер і клієнт перезапускаються при змінах коду, логи читабельні, налаштування беруться з `api/.env` (приклад у `api/.env.example`), а порожня база заповнюється демонстраційними даними.
- `./run.sh prod` відкривається на http://localhost:8000. Спершу скрипт перевіряє код лінтером ruff і типи за допомогою mypy та збирає клієнт, потім запускає один процес Uvicorn, який роздає і клієнт, і API. Логи йдуть у JSON, налаштування беруться лише зі змінних середовища.
