Технологічні карти деталей

Технологічна карта описує маршрут обробки деталі: послідовність операцій із видом обробки, обладнанням і тривалістю. Дані зберігаються в MongoDB, а клієнт працює з ними через REST API на FastAPI з повним циклом CRUD. Усі запити можна переглянути й випробувати на сторінці «API».
